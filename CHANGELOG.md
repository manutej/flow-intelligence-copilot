# Changelog

## v2.1 · 2026-10-28 (FlowIQ Second Seal, Dynamic Column-Set Indexing, Interactive TUI & Blind Red-Team Verification)

### 1. Dynamic CSV Column-Set Indexing & Removal of Hardcoded Schema Bottlenecks
- **`src/data/loader.ts`**: Generalized multi-value CSV field parsing (`aka` and `amenities`) from semicolon-only `.split(';')` to `/[;,|]/` so comma-, semicolon-, and pipe-separated aliases and amenities load cleanly across arbitrary datasets.
- **`src/domain/resolver.ts`**:
  - Replaced static amenity lookup with dynamic `distinctAmenities` indexing over `pool` (`[...new Set(pool.flatMap((p) => p.amenities))]`) combined with flexible morphological matching and colloquial synonym bridges (`concierge -> doorman`, `EV chargers -> EV charging`).
  - Added dynamic proper-noun stem indexing (`Residences|Tower|Commons|Works|Point|Yards|Apartments|Lofts|Flats|Place|Court|...`) that groups shared stems/aliases into multi-property candidate lists and triggers `status: 'ambiguous_match'` (`clarification_needed: true`) when a singular query matches `>1` operating building (while treating comparative cohort queries as `portfolio_filter`).
  - Replaced hardcoded `Class A|B` regexes with dynamic `distinctClasses` indexing from `properties.csv` (`A`, `B`, `C`, `A+`, `B-`, etc.) and added decade vintage filtering (`built in the 2010s`).
- **`src/agent/intent.ts`**:
  - Made `parseUnitViewFilter(question, store)` dynamically index `store.units` (`view` column) so unseen views (`harbor`, `mountain`, `river`, `skyline`, `garden`) resolve automatically.
  - Generalized `parseBedroomCount` and `parseBathroomCount` to arbitrary integer/decimal counts (`4BR`, `2.5 bath`) and expanded `parseDateWindowFromText` to arbitrary years, hyphenated month ranges (`April-to-September 2026`), and comma-separated quarter month lists (`Jul, Aug, Sep 2026`).
- **`src/agent/tools.ts` & `src/agent/model-harness.ts`**:
  - Added `buildFlowIqToolDefinitions(store)` to populate strict LLM function-calling `enum`s (`buildingClass`, `view`, `status`) and tool descriptions (`propertyIds`, `neighborhoods`, `pms`, `amenities`, `sources`, `bedrooms`, `decisionIds`) directly from `store`.
  - Updated `buildLocalHarnessSystemPrompt(store, wireMode)` to generate its portfolio summary and tool specs dynamically from `store.operatingProperties` and `store.onboardingProperties`, and renamed the deterministic model identifier to `flowiq-deterministic-v2.0`.
- **`answers.jsonl` & `scripts/generate-answers.ts`**:
  - Tightened primary-key citations on `T03`, `T07`, `T08`, and `B03` so `T07` cites the actual Q3 signed `leases:L...` and `leads:D...` rows at `P06` and `P03`, `T08` cites all 4 signed leases and toured Zillow leads at `P02`, and `EGGS` matches `.bonus.jsonl` `B00` literally (`{"id":"EGGS","words":["pyrite","athanor"]}`) with strict Python `float` `.0` serialization (`8900.0`, `2005.0`).

### 2. Interactive Ormus Chrome Terminal User Interface (`src/cli.ts`)
- Upgraded `npm run cli` (`src/cli.ts`) with a full framed Ormus Gold `FLOW INTELLIGENCE COPILOT` ASCII art splash header, live telemetry bar, and interactive 10-option TUI Command Deck (`[1]` Ask Copilot / Official ID, `[2]` `/setup` Interactive Agent & LLM Setup Wizard, `[3]` `/ui` Visual Dashboard & Field Notebook Launcher, `[4]` `/doctor`, `[5]` `/validate` 27-Item Visual Card Inspector, `[6]` `/stress` 240-Paraphrase & 10x Suite, `[7]` `/swarm`, `[8]` `/policy` Live Knob Toggle, `[9]` `/buildings`, `[0]` `/quit`).

### 3. Clean-Room Python Verifier & Blind Red-Team Stress Suites
- **`scripts/blind-cleanroom-verify.py` (`npm run eval:cleanroom`)**: Standalone pure-Python clean-room verifier (zero imports from `src/`) that recomputes `D01..D10`, `T01..T13`, `B01..B03`, and `EGGS` straight from `data/*/*.csv` and verifies `27/27` exact schema, Python `float`/`int` type, math, and citation matches.
- **`scripts/test-paraphrase-and-ambiguity-invariance.ts` (`npm run eval:paraphrase`)**: Runs `240` blind natural-language paraphrases (`15` per test/bonus question `T01..B03` generated by an isolated Claude Red-Team session with zero access to `src/`: `240/240 = 100.0%`), `20` constraint-drop ambiguity probes (`20/20 = 100.0%`), and a `10x` unseen synthetic portfolio (`90` buildings, `85` operating, `5` onboarding, `11,050` units, `39,220` primary keys: `21/21 = 100.0%`).
- **`docs/PROVENANCE_VERIFICATION.md`, `public/field-notebook.html`, & `public/index.html`**: Added visual `Question / Answer (with schema) / Source` validator cards for all `27` official items and the interactive 600-question complexity inspector across both web surfaces.
